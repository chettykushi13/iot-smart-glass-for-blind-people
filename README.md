
# IoT-Based Smart Glass for Blind People

An IoT-based assistive smart glass prototype designed to help visually impaired individuals detect nearby obstacles using sensors and audio alerts.

## Project Overview

The Smart Glass system uses an ESP32 microcontroller and sensors to detect obstacles in three directions: front, left, and right.

When an obstacle is detected, the system provides audio alerts through a buzzer to help the user identify potential obstacles while walking.

## Features

- Front obstacle detection
- Left-side obstacle detection
- Right-side obstacle detection
- Real-time obstacle sensing
- Audio alerts through a buzzer
- Portable smart glass prototype

## Technologies and Components

- ESP32 Microcontroller
- Ultrasonic Sensors
- IR Sensor
- Buzzer
- Arduino IDE

## Working Principle

1. Sensors continuously monitor the surrounding area.
2. The ultrasonic and IR sensors detect nearby obstacles.
3. The ESP32 processes the sensor readings.
4. Based on the detected direction, the system activates audio alerts.
5. The user receives alerts about obstacles in front, left, and right directions.
